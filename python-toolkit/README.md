# Small Business Toolkit (Python)

A collection of Python functions that solve everyday business problems, such as splitting bills, calculating payroll, tracking inventory, applying customer pricing rules, and analyzing weekly sales.

## What it does

| Area | Examples |
|------|----------|
| Pricing & Payments | Split a bill, apply discounts, add sales tax, calculate shipping |
| Payroll & Finance | Weekly pay with bonus, compound investment growth |
| Inventory | Pack items into boxes, find low-stock products |
| Customer Rules | Membership pricing, masked card numbers, pickup labels, password check |
| Sales Analysis | Total sales, best day, average sale, delivery distance |

## Skills used

- Arithmetic and formulas
- Conditional logic (`if / elif / else`, `and / or`)
- Loops and accumulators
- Lists and list comprehensions
- String formatting and slicing
- The `math` module

## How to run

```bash
python business_toolkit.py
```

Running the file prints a demo of every function with sample data.
